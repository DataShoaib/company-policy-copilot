# IT and Information Security Policy

Document ID: IT-001
Version: 1.0
Effective: January 1, 2026

## Account Security
Employees must use multi-factor authentication for company systems and must never share passwords or authentication codes. Passwords must be at least 12 characters and changed immediately when compromise is suspected.

## Device and Remote Access
Company laptops must use full-disk encryption, automatic screen lock after 10 minutes, and approved endpoint protection. Remote access to internal systems requires the company VPN and multi-factor authentication. Contractors connect through the restricted VPN access group VPN-CNT-1, which does not grant access to source-code repositories.

## Security Incidents
Employees must report a suspected phishing message, lost device, or data exposure to security@techcorp.in within 24 hours. The IT Security team acknowledges reports within one business day.

## Data Handling
Confidential company data must be stored only in approved company systems. Public AI tools, personal email, removable media, and personal cloud drives must not be used for confidential or personal data.

## Access Reviews
System access is granted using least privilege and must be reviewed by the manager every 6 months. Access must be removed within one business day after a role change or departure is confirmed.

## Software Changes
Employees may install only software approved by IT. New software requests must be raised through the IT self-service portal using service request code IT-SW-117; requests are reviewed by the IT Security team within 5 business days. Security updates must be installed within 7 days of release, or sooner when IT marks an update critical.
